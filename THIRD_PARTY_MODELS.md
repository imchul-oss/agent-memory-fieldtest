# Third-party tools and models

This repository ships no model weights and no third-party code. This page lists the tools and models that the
result table refers to, with the license each one declares and a place to read about it. Licenses were read from the
public package or model pages on 2026-11-21 and can change; check the source before you rely on one.
A tool whose only public page is its code hosting page is linked to that page.
