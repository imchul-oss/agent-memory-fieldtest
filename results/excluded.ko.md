# 결과표에 싣지 않은 구성

<!-- disclaimer --><sub>개인이 직접 해 본 실험의 결과이며, 절대적인 평가나 순위가 아닙니다. 자료와 환경, 설정이 다르면 결과도 달라질 수 있습니다. 각 도구의 이름과 상표는 해당 소유자의 것이고, 이 저장소는 그 제작사와 관계가 없습니다.</sub>

이 문서는 [README](../README.ko.md)의 결과표에 싣지 않은 구성 83개를 모아 둔 문서입니다. 잰 뒤에 뺀 것이 50개, 돌리지 않고 결과를 예상해 닫은 것이 13개, 잴 수 없었던 것이 20개입니다. 도구 이름은 각 도구가 스스로 부르는 그대로 적었습니다. 표에서 뺀 구성을 이름으로 적은 곳은 이 문서뿐입니다.

이 문서의 점수는 README 표의 점수와 같은 조건으로 견줄 수 없습니다. README 표에는 도구가 권하는 구성대로 끝까지 돌렸고 실행 점검을 통과한 구성만 있습니다. 예외는 베이스라인[^baseline], 참고 행 하나, 중간 결과만 있어 보류 중인 Hindsight 셋뿐입니다. 여기 있는 행은 권장 구성이 아니거나 끝까지 돌지 못했고(축소한 구성, 우리가 바꾼 부품, 절반만 만들어진 저장소), 행마다 구성이 서로 다르며(노트 파일을 스스로 읽는 에이전트도 있고 우리가 만든 조합도 있습니다), 한 번만 돌려서 몇 문항 차이는 우연일 수 있기 때문에 뺐습니다. 점수는 까닭과 함께 읽어 주십시오.

Hit@5[^hit5] 칸은 질문 100개 가운데 정답 노트가 상위 5개 안에 든 질문의 수입니다. 승과 패는 베이스라인[^baseline], 곧 우리 한국어 BM25[^bm25] 검색과 같은 질문끼리 견준 수이고, p값[^p]은 정확 양측 부호 검정[^sign]으로 구했습니다. p값이 0.05 이상인 행은 베이스라인과 확인된 차이가 없습니다. 까닭 칸에는 임베딩[^embedding] 모델, 리랭킹[^rerank] 단계, 에이전트 검색[^agent]이 나옵니다. 에이전트 검색은 모델이 검색 도구로 노트 파일을 단계적으로 찾아 읽는 방식입니다. 돌리지 못했거나 예상으로 닫은 행은 점수가 없어서 점수 칸에 -를 적었습니다.
